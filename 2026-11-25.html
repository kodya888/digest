Итог дня

Главная линия дня — фундаментальная математика удешевления ИИ: доказательство Θ(n^2.25) для матричного умножения прямо бьёт в стоимость всех вычислений нейросетей, а Bonsai 2.5 с ternary-весами продолжает сжимать модели для слабого железа — обе новости работают в сторону «ИИ становится дешевле», и обе вам на руку. Вторая линия — вайбкодинг на государственном уровне: GitHub-issue про CIO Казначейства США рядом с хабровской историей про CRM из автосервиса — метод стал мэйнстримом, но оба кейса показывают одну границу: вайбкодинг работает, когда за ним стоит конкретная задача и ответственность, и ломается, когда им решают не свою работу. Третья линия — практика для вас: приватность ФИО через API (падежи локально без данных), раскладка цен на DeepSeek API из РФ, и напоминание из эксперимента с резюме — автоматические скринеры решают не по «командам», вписанным в документ. Плюс мелочь в копилку PWA: техники обхода 60 FPS на iOS Safari и библиотека звуков кнопок — дешёвые способы добиться «ощущения настоящего приложения».
